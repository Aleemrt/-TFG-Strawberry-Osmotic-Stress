# BRIEF — Construcción de base de datos funcional y bibliográfica curada para genes core UP y DOWN en estrés osmótico

## Contexto del proyecto

Estoy desarrollando un Trabajo de Fin de Grado (TFG) en biología molecular vegetal enfocado en la identificación y caracterización funcional de genes core implicados en la respuesta al estrés osmótico (sequía y salinidad) en plantas.

Voy a proporcionarte dos archivos CSV independientes:

* **UP_genes.csv** → genes up-regulated
* **DOWN_genes.csv** → genes down-regulated

Ambos archivos contienen genes core previamente filtrados a partir de análisis transcriptómicos (RNA-Seq).

El objetivo es construir una base de datos científica curada y completamente trazable para poder analizar posteriormente la función de estos genes y los procesos biológicos implicados.

Por ahora NO quiero construir un modelo biológico; solo quiero recopilar información funcional y bibliográfica sólida.

---

# INPUT

Cada CSV contiene únicamente:

* **Gene_ID**
* **gene_annotation**

Debes usar ambos campos para identificar correctamente cada gen.

Si la anotación contiene IDs de UniProt, TAIR, InterPro, NCBI u otras bases funcionales, debes utilizarlos como referencia principal.

---

# OBJETIVO PRINCIPAL

Construir tres bases de datos independientes:

## 1. Base de datos funcional y bibliográfica para genes UP

## 2. Base de datos funcional y bibliográfica para genes DOWN

## 3. Base de datos bibliográfica general sobre estrés osmótico

Las bases UP y DOWN deben mantenerse separadas durante todo el análisis.

# REQUISITO CRÍTICO SOBRE LA FUNCIÓN GÉNICA

No quiero funciones vagas o demasiado generales.

Ejemplos NO válidos:

* stress response
* signal transduction
* cell wall organization

Ejemplos válidos:

* degradación de celulosa
* remodelación de xiloglucanos
* síntesis de lignina
* modificación de pectinas
* biosíntesis de prolina osmoprotectora
* transporte Na+/H+
* detoxificación de ROS
* regulación ABA dependiente de cierre estomático
* transporte de agua por acuaporinas

La función debe ser lo más específica y mecanística posible.
